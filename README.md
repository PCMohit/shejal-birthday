# Shejal Birthday Surprise 🎂

Mobile-first birthday surprise website for Shejal, made by Mohit.

## Files
- `index.html` — page structure/content
- `style.css` — mobile-first cinematic styling
- `script.js` — quiz, secret reveal, dodging NO button, confetti
- `assets/` — supplied photos and video

## GitHub Pages
1. Create a new GitHub repository (for example `shejal-birthday`).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish.
6. Open the generated Pages URL on your phone.

The site intentionally has no background music because no audio file was supplied. The video is included with native mobile controls.


## Advanced features
- Cinematic loading screen and reading-progress bar
- Scroll-reveal animations with reduced-motion support
- Unified responsive photo lightbox with captions
- Previous/next controls, keyboard navigation, and mobile swipe navigation
- Floating back-to-top control
- Lazy-loaded images for better mobile performance
